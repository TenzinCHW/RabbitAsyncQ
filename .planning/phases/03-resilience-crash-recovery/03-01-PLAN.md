<objective>
Implement crash recovery and process pool monitoring for isolated worker processes.

Purpose: Ensure the RabbitMQ connection cleanly handles `BrokenProcessPool` exceptions and worker crashes by NACKing the affected messages, allowing them to be sent to a dead-letter queue or retried, and terminating the parent process if the pool cannot recover.
Output: An updated `JobManager` that attaches callbacks to `ProcessPoolExecutor` futures and safely NACKs failed jobs without infinite requeueing.
</objective>

    Per D-03: If the pool is broken (`BrokenProcessPool`), it should log the failure, clean up the connection, and terminate the process (e.g., `os._exit(1)` since this callback runs in a background thread and `sys.exit()` might only kill that thread).
  </action>
