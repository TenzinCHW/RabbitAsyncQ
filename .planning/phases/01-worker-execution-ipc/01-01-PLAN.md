  <name>Task 1: Process Worker Abstraction</name>
  <files>rabbitasyncq/job.py</files>
  <action>
    Replace the `StoppableThread` and `StoppableJob` classes with a process-safe function and state tracker (per D-01, D-02).

    1. Import `multiprocessing`.
    2. Create a top-level function `process_worker(job_id: str, job_fn, body: bytes, ipc_queue, stop_event)`:
       - Iterate over `job_fn(body)`.
       - On each iteration, check if `stop_event.is_set()`. If true, `ipc_queue.put({"job_id": job_id, "type": "stopped"})` and `return`.
       - If not stopped, put `{"job_id": job_id, "type": "result", "payload": result}` into the queue.
       - If the loop finishes naturally, put `{"job_id": job_id, "type": "done"}`.
       - Wrap in `try...except Exception as e`, and on error, put `{"job_id": job_id, "type": "error", "message": repr(e)}` (per D-03).
    3. Create a class `ProcessJobContext`:
       - Tracks state in the main process.
       - `__init__(self, job_id, method, ch, name, stop_event, messenger)`
       - Add a `.stop()` method that calls `self.stop_event.set()`.
       - Store `self.future = None` to eventually hold the `ProcessPoolExecutor` future.
  </action>

<task type="auto">
  <name>Task 2: JobManager Pool and IPC Integration</name>
  <files>rabbitasyncq/manager.py</files>
  <action>
    Integrate `JobManager` with `ProcessPoolExecutor` (per D-04) and drain the `ipc_queue`.

    1. Update imports: import `ProcessPoolExecutor` from `concurrent.futures`, `multiprocessing`, `functools`. Import `process_worker` and `ProcessJobContext` from `.job`.
    2. In `__init__`:
       - Initialize `self.manager = multiprocessing.Manager()` and `self.ipc_queue = self.manager.Queue()`.
       - Initialize `self.executor = ProcessPoolExecutor()`.
       - Start an IPC consumer thread: `self.ipc_thread = threading.Thread(target=self._consume_ipc)` and `start()` it before the RabbitMQ `consume_thread`.
       - Save `self.consume_thread` as an instance attribute so we can join it later.
    3. Implement `_consume_ipc(self)`:
       - Loop `while True: msg = self.ipc_queue.get()`. Break if `msg is None`.
       - Look up `ctx = self.jobs.get(msg["job_id"])`.
       - Use `self.conn.add_callback_threadsafe()` to schedule the relevant actions based on `msg["type"]` (result, error, stopped, done).
       - **CRITICAL:** When passing `ctx` or payloads to lambdas inside `add_callback_threadsafe`, you MUST use default arguments (e.g., `lambda c=ctx, p=payload: c.messenger...`) or `functools.partial` to avoid Python late-binding scoping bugs.
       - Delete the job from `self.jobs` when processing `error`, `done`, or `stopped`.
    4. Update `accept_job`:
       - Create `stop_event = self.manager.Event()`.
       - Create `job_ctx = ProcessJobContext(...)`, assign to `self.jobs[job_id]`.
       - Submit to pool: `future = self.executor.submit(process_worker, job_id, self.job_fn, job_data, self.ipc_queue, stop_event)`.
       - Assign `job_ctx.future = future`.
    5. Update `stop_job`: Call `ctx.stop()` instead of `join()`. Do not delete the job here; let `_consume_ipc` delete it when it receives `"stopped"`.
    6. Implement `shutdown(self)`:
       - `self.conn.add_callback_threadsafe(self.ch.stop_consuming)`
       - `self.consume_thread.join()`
       - `self.ipc_queue.put(None)`
       - `self.ipc_thread.join()`
       - `self.executor.shutdown(wait=False)`
       - `self.manager.shutdown()`
  </action>
  <verify>

  </verify>
  <done>JobManager delegates execution to a pool and processes streamed results without blocking.</done>
