  <name>Task 1: Blocking `start()` and Signal Handlers (D-04, D-05)</name>
  <files>rabbitasyncq/manager.py</files>
  <action>
    In `JobManager.__init__`, remove the `self.consume_thread` assignment and `.start()` calls. Leave `self.ipc_thread` running in the background.

    Add a new method `start(self)` that runs in the calling thread.
    Inside `start(self)`:
    - Define `_sig_handler(signum, frame)`: This handler must log the shutdown request and call `self.conn.add_callback_threadsafe(self.ch.stop_consuming)`.
    - Register this handler for `signal.SIGINT` and `signal.SIGTERM`.
    - Call `self.ch.start_consuming()` to block the main thread.
    - Right after `start_consuming()` returns, call `self.shutdown()`.

    In `self.shutdown()`, remove the check for `self.consume_thread.is_alive()` since it no longer exists.
    Make sure to import `signal` at the top of the file.
  </action>

  </verify>
